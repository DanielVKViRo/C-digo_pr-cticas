# Código y documentación de las prácticas de empresa

Este repositorio contiene el material generado durante las prácticas de empresa realizadas en el Máster en Bioinformática y Biología Computacional.

## Contenido

El repositorio incluye:

* Tres documentos de texto (`.txt`) que describen los procedimientos seguidos.
* Tres scripts de shell (`.sh`) desarrollados para automatizar distintas tareas.

## Observaciones

Los datos utilizados durante las prácticas no se incluyen en este repositorio debido a su carácter confidencial. Por este motivo, los scripts proporcionados no pueden ejecutarse de forma completa sin acceso a los datos originales.

La finalidad de este repositorio es documentar el trabajo realizado y poner a disposición los scripts desarrollados durante las prácticas.
